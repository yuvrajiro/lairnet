Usage notebooks
===============

Four notebooks, run end to end and committed with their outputs. Every number,
warning and figure on these pages came out of the package on the machine that
built the docs — ``nb_execution_mode`` is ``off``, so Sphinx renders what was
stored rather than running anything at build time.

That is a deliberate choice with a consequence worth stating: a notebook here
shows what the code *did*, not what it is expected to do, but only because
``python docs/make_notebooks.py`` executed it first. Re-run that script after
any change that could move these numbers.

Running them yourself
---------------------

The notebooks live in ``docs/examples/`` and depend only on the package and
scikit-learn's built-in datasets, so they run offline:

.. code-block:: bash

   pip install lairnet[plots]
   jupyter lab docs/examples

To rebuild and re-execute all four in place:

.. code-block:: bash

   python docs/make_notebooks.py

The notebook sources are generated by that script rather than edited by hand,
so an edit made in Jupyter will be overwritten the next time it runs. Change
the cell text in ``docs/make_notebooks.py``.
